# Pruebas

| Carpeta | Tipo de prueba |
| --- | --- |
| `unitarias/` | Funciones y componentes aislados |
| `integracion/` | Componentes trabajando en conjunto y contra la base de datos |
| `rendimiento/` | Tiempos de respuesta, especialmente en la operación de caja |
| `seguridad/` | Control de acceso y resguardo de la información |

Los planes de prueba y sus resultados se documentan en `docs/11-pruebas/`.

> **Responde al instructivo:** pruebas unitarias, de integración, de rendimiento y de seguridad.
