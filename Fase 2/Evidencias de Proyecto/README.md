# Fase 2 · Evidencias de Proyecto

Evidencias del sistema construido, no de la gestión académica.

| Evidencia | Qué incluir |
| --- | --- |
| `Presentación Proyecto.pptx` | Presentación del avance del proyecto |
| Evidencias de documentación | Capturas o extractos de la documentación técnica producida |
| Evidencias de sistema / aplicación | Capturas del sistema funcionando, registro de las pruebas |
| Base de datos | Modelo, diagrama entidad-relación, evidencia del esquema desplegado |

> Estas evidencias **se apoyan en lo que ya vive en `docs/`, `src/` y `database/`**. Aquí van los extractos que se entregan a la asignatura, no una copia del proyecto completo.
>
> ⚠️ **No subir aquí datos reales del negocio**: ni el archivo de base de datos del local, ni volcados con nombres o saldos de clientes.
