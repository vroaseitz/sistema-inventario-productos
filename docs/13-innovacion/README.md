# 13 · Innovación

Sección de innovación del proyecto.

## Qué va aquí

Qué aporta este proyecto más allá de replicar lo que ya existe: decisiones, enfoques o soluciones que agregan valor frente al sistema actual y frente a alternativas comerciales.

## Puntos candidatos

- Reemplazo de un sistema descontinuado y sin soporte por una solución mantenible
- Base de datos gestionada, en lugar de un archivo local con conexión única y respaldo de 10 días
- Diseño preparado para productos pesables y códigos de barras con peso embebido, anticipando una futura balanza etiquetadora
- Estrategia de migración ensayada con plan de reversa, en vez de un corte a ciegas

> **Responde al instructivo:** innovación (obligatorio transversal).
