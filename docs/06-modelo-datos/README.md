# 06 · Modelo de datos

Modelo entidad-relación y diccionario de datos del sistema nuevo.

## Qué va aquí

- Diagrama entidad-relación (ER)
- Diccionario de datos: tablas, campos, tipos, restricciones
- Reglas de negocio reflejadas en el modelo
- Mapeo entre el modelo antiguo (Firebird) y el nuevo, para la migración

## Áreas que debe cubrir el modelo

Productos · Inventario · Ventas · Formas de pago · Caja · Clientes · Crédito

> **Responde al instructivo:** modelo de datos, ER clásico para SQL (obligatorio transversal).
