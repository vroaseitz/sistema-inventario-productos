# 12 · Manual técnico de despliegue

Documento que permite instalar, poner en marcha y revertir el sistema.

## Qué debe contener

1. **Requisitos** de hardware y software del equipo del local
2. **Instalación** paso a paso del sistema
3. **Variables de entorno**: qué configurar y dónde, a partir de `config/.env.example`
4. **Ejecución de la migración** de datos
5. **Verificación** posterior al despliegue
6. **Procedimiento de reversa**: cómo volver al sistema antiguo si algo falla

## Por qué este documento es crítico

Reemplaza el punto de contenedores del instructivo, cuya excepción fue autorizada por la profesora guía con la condición de cumplir mecanismos equivalentes. Este manual es el principal de ellos.

> **Responde al instructivo:** manual técnico de despliegue.
