# 01 · Diagnóstico del sistema actual

Análisis del software que Emporio NaturalSur utiliza hoy y de las limitaciones que justifican su reemplazo.

## Qué va aquí

- Ficha del producto: Abarrotes Punto de Venta 2.12, Bambu Code S.A. de C.V., 2010
- Análisis de la base de datos `PDVDATA.FDB` (Firebird embebido) y su estructura
- Limitaciones técnicas: conexión única, respaldo de 10 días, corrupción de base, módulo fiscal CFDI
- Limitaciones funcionales: sin módulo de compras ni proveedores, margen bruto sin utilidad neta
- Problemas de calidad de datos detectados en los productos
- Evidencias: capturas, exportaciones de muestra, registro de hallazgos
