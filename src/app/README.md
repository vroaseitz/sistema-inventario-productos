# Aplicación de escritorio

Punto de venta e inventario de Emporio NaturalSur. Se ejecuta en el equipo del local, sobre Windows, contra la base de datos en Supabase.

## Módulos

| Módulo | Contenido |
| --- | --- |
| Productos | Códigos, nombres, descripciones, marcas, categorías, unidades, imágenes, estados |
| Inventario | Existencias, ajustes, productos por unidad y a granel |
| Ventas | Registro de la venta y cálculo de totales |
| Pagos | Formas de pago de cada venta |
| Caja | Apertura, movimientos y cierre de turno |
| Clientes y crédito | Registro de clientes y administración de sus créditos |
